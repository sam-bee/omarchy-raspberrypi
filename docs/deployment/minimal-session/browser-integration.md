# Browser integration acceptance

Use a disposable browser profile and a bounded test page or local fixture. Keep the acceptance record and any captures in the private deployment evidence for the target machine.

Check the browser's hardware-compositing status, video playback clock, audio stream through the selected local sink, native file chooser, clipboard, downloads and profile cleanup. Record the display backend and decoder path. Treat high-resolution performance, real uploads and reboot persistence as separate checks.

Do not publish account names, home paths, network addresses, device identifiers, physical peripheral names or screenshots containing personal data in this repository.
